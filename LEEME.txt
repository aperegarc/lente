¿QUÉ INCLUYE?
================================================================================

✅ Frontend PWA (HTML/CSS/JS vanilla)
   - App instalable en móvil
   - Dark mode + diseño premium
   - Service worker para offline
   - Responsive en todos los tamaños

✅ Backend serverless (Vercel)
   - 12 endpoints completamente funcionales
   - Validación de variables de entorno
   - Manejo robusto de errores
   - Logs claros para debugging

✅ Pipeline de IA automático
   - Ingestión RSS de 8 medios (2x/día)
   - Embeddings con OpenAI
   - Clustering inteligente (cosine similarity)
   - Generación con Claude Sonnet 4.5
   - Revisión humana (admin panel)

✅ Admin panel completo
   - Ver tarjetas pendientes/aprobadas/rechazadas/publicadas
   - Editar cualquier campo
   - Aprobar/rechazar en batch
   - Disparar ingestión/generación manualmente

✅ Base de datos (Supabase)
   - Schema SQL listo para ejecutar
   - Tablas: articles, clusters, cards, markets, profiles, saved_cards
   - Row Level Security (RLS) configurado
   - Autenticación con magic links

✅ Documentación
   - 5 archivos de documentación (.md)
   - Instrucciones paso a paso
   - Guía de troubleshooting
   - Explicación de costes y roadmap
